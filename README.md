# 📊 Customer Churn Analysis in E-commerce Using Python

## 📌 Overview
This project was completed as part of my **Data Analytics Internship at Alfido Tech**. The objective was to analyze customer churn and purchasing behavior using Python by performing data cleaning, exploratory data analysis (EDA), and data visualization to uncover meaningful business insights.

---

## 🎯 Objectives
- Analyze customer churn patterns.
- Identify high-value customers.
- Study product category performance.
- Analyze product return trends.
- Understand customer payment preferences.
- Generate actionable business insights for customer retention.

---

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📂 Dataset
The dataset contains customer purchase records, including:
- Customer ID
- Gender
- Product Category
- Product Price
- Quantity
- Total Purchase Amount
- Payment Method
- Returns
- Churn
- Purchase Date

---

## 📈 Analysis Performed
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Customer Churn Analysis
- Product Category Analysis
- Quarterly Sales Analysis
- Product Return Analysis
- Top Customer Analysis
- Payment Method Distribution
- Correlation Analysis

---

## 📊 Visualizations
- Total Purchase Amount by Product Category
- Quarterly Sales Trend by Product Category
- Category-wise Returns
- Top 10 Customers by Total Purchase Amount
- Customer Churn by Gender and Product Category
- Payment Method Distribution (Pie Chart)
- Correlation Heatmap

---

## 💡 Key Insights
- Customer churn varies across gender and product categories.
- A small group of customers contributes a significant portion of total revenue.
- Product return rates differ across categories.
- Sales trends vary across different quarters.
- Payment preferences provide insights into customer purchasing behavior.
